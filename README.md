## 🌟 Features

- **Multiple Schema Types:** Generate dummy records for Sales, Order Logistics, Mail, Green Marketing and more.
- **Instant Export:** Export tabular outputs directly to clean, formatted `.csv` files.
- **Privacy-Safe:** 100% synthetic data—no real-world personal identifiable information (PII) involved.
- **No Signup Required:** Free to use directly in your browser without account creation or API keys.

## 🚀 How to Use

1. Visit **[https://info-gen.in](https://info-gen.in)** in your web browser.
2. Select your desired dataset schema (e.g., *Sales Data* or *Order Logistics Data*).
3. Configure your required parameters or column names or select all for all columns.
4. Click **Submit ** and click 'Download .csv' to download your generated `.csv` file.

---

## 💡 Common Use Cases

- **Machine Learning & Data Science:** Train and benchmark models (Pandas, Scikit-Learn, PyTorch) using realistic mock data.
- **Database Benchmarking:** Seed PostgreSQL, MySQL, or MongoDB databases with test records to evaluate query speeds.
- **Dashboard Prototyping:** Build quick mockups in Tableau, Power BI, or Looker Studio without waiting for production data access.
- **GDPR / Compliance Safety:** Test data pipelines safely without risking exposure of real user or company metrics.
